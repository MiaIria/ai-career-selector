# 路上见

> 陪你把每一步都照亮。

“路上见”是一款面向大学生的 AI 职业决策支持产品。它会结合你的学业情况、能力经历、兴趣偏好和现实约束，对多条发展路径进行推演，帮助你在真正投入时间和精力之前，看清关键节点、准备差距、成本、风险与备选方向。

## 在线体验

[立即体验“路上见”](https://pathpilot.taro.black)

无需登录即可完成画像、辅助决策和路径推演；确认并保存选择、生成个人阶段方案时需要注册或登录。

## 适合谁使用

- 正在考研、考公、就业之间犹豫的大学生
- 想了解不同选择需要提前准备什么的人
- 有多个目标，但不知道主线和副线如何安排的人
- 希望结合个人条件，而不是只看通用经验做决定的人

## 你可以获得什么

### 证据化画像

从专业、年级、学业水平、能力、经历、兴趣、价值偏好、地域、时间和资金约束等方面梳理个人情况。系统会区分用户自述、已有证明和外部规则，避免把主观判断当成确定事实。

### 辅助决策

结合画像信息比较不同方向，展示推荐依据、主要风险和仍需补充的信息。系统建议只是决策参考，你可以根据自己的真实意愿调整主路径和成长副线。

### 四轨路径推演

每条路径以关键节点和分支呈现，帮助你了解进入条件、当前基础、能力缺口、时间窗口、投入成本、潜在风险、下一步行动和替代走向。

### 个人阶段方案

确认主路径与成长副线后，系统会结合你当前所处的学业阶段生成连续成长方案，并提供行动步骤、节点依据和完成标准。

## 四条发展路径

| 方向 | 主要路径 | 关注重点 |
| --- | --- | --- |
| 升学深造 | 考研、保研 | 学业基础、院校选择、备考节奏与录取条件 |
| 体制内发展 | 公务员、事业单位 | 选岗、报名、笔试、面试、体检考察与录用聘用 |
| 市场化就业 | 校招 | 行业与岗位选择、技能证明、实习项目与求职窗口 |
| 自主发展 | 内容创作、OPC 一人公司 | 方向验证、作品产出、用户需求与可持续收入 |

## 使用流程

1. 填写基本信息，建立个人画像。
2. 完成结构化题组，获得辅助决策结果。
3. 查看四条路径及其关键节点推演。
4. 结合系统依据和个人意愿，确认主路径与成长副线。
5. 注册或登录，保存选择并生成个人阶段方案。

## 使用说明

- 路径中的时间节点和招录、招聘规则会随年份、地区、院校及单位变化，请以当年官方公告为准。
- 可行性判断基于你当前提供的信息，不等同于录取、上岸、Offer 或收入承诺。
- 产品不会输出缺乏可靠样本依据的精确成功率。
- 游客数据仅用于当前体验；如需保存选择和阶段方案，请注册或登录。
